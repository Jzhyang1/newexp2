# Markov-fitted counterpart to configs/ycsb_a.txt.
#
# Zipfian(0.99) draws each page i.i.d., so there's no real "page X is followed
# by page Y" structure for cminer/quickmine/mithril to mine -- see README.md's
# "Markov workload" section. This config instead fits a non-parametric Markov
# model from the first 10000 pages a Zipfian(0.99) generator itself produces,
# then generates the actual request stream from that model, so prefetching
# has genuine (if synthetic) sequential structure to find.
markov base=zipfian samples=10000 alpha=0.99 relative-weight=0.99
markov base=zipfian samples=10000 alpha=0.99 relative-weight=0.99
markov base=zipfian samples=10000 alpha=0.99 relative-weight=0.99
markov base=zipfian samples=10000 alpha=0.99 relative-weight=0.99
